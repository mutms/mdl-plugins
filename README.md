# mdl-plugins

Plugin metadata catalogue for [mudev](https://github.com/mutms/mudev): one YAML file per
plugin, grouped by vendor at `<vendor>/<package>.yaml` (identifier `vendor/package`). See
mudev's `docs/plugin-format.md` for the format and the embedded JSON Schema.
